Designed for seamless local AI.

Experience fluid conversations, visual reasoning, document search, and speech synthesis right on your Android device.

A complete local AI stack.

Modular native Kotlin engines wrapped around low-level C++ backends for maximum device performance.

⚡

Native GGUF Inference

Run quantized Llama 3, Qwen 2.5, Gemma 2, and Phi-3 models locally using JNI bindings for llama.cpp. Supports sliding-window context and GBNF grammar constraints.

engine = "llama.kt"
quant = "Q4_K_M"
context = 4096 tokens
🎙️

Real-Time Speech (STT / TTS)

Offline Sherpa-ONNX Whisper speech-to-text combined with VITS and Piper neural speech synthesis for continuous, natural voice conversations.

stt = "Sherpa-Whisper-Tiny"
tts = "VITS LJSpeech / Piper Amy"
vad_silence = "950ms"
📄

On-Device RAG Retrieval

Query local PDFs, Word documents, Excel sheets, and plain text files with hybrid vector semantic search and BM25 full-text indexing using neuron-packet format.

module = "neuron-packet"
ranking = "Vector + BM25"
index = "Local Keystore Encrypted"
🧠

Long-Term Episodic Memory

Persist user facts, preferences, and context across chat sessions using configurable memory decay curves in the memory-vault engine.

module = "memory-vault"
decay = "Exponential Curve"
recall = "Contextual Query Mapping"
👁️

Vision Language Multimodal

Analyze images, charts, and visual documents on-device using CLIP vision projectors paired with quantized GGUF multimodal backends.

projector = "mmproj-Qwen2-VL"
pipeline = "On-Device CLIP Tensor"
🔒

Encrypted Local Backups

Export chat history, custom model parameters, and memory states to encrypted .tnbackup packages backed by Android Keystore System AES-256-GCM.

cipher = "AES-256-GCM"
keystore = "Android KeyStore System"
