Changelog

The development history and release notes for BIT.

v2.1.0-beta.1 August 20, 2026

PRoot Linux Terminal Session Persistence, Process Management, Swipe-to-Delete, and Community Infrastructure.

  • Persistent Multi-Terminal Routing: Isolated PRoot Linux terminal sessions remain active and persistent across app lifecycle and navigation. Added interactive tab switcher to toggle and spawn multiple concurrent shell sessions.
  • Process & Task Management: Comprehensive task manager for background AI tools and interactive terminal processes with direct termination, deletion, and physics-based swipe-to-delete.
  • Workspace File Operations: Added physics-based swipe-to-delete gestures and Material 3 destructive confirmation dialogs for workspace files and directory trees.
  • Community & Issue Templates: Structured GitHub issue forms for Bug Reports, Feature Requests, and Discord community integration.
v2.0.9 August 15, 2026

Material 3 Intelligence & Tools Overhaul, Full Settings Search, and Native VLM Engine Stability.

  • Material 3 Intelligence & Tools: Redesigned Intelligence Settings with direct tool calling bypass, multi-turn tool loops, and granular controls for all 4 built-in agent plugins (Live Web Search, File Manager, System Diagnostics, Memory Vault).
  • AI Memory Screen Revamp: Modernized memory management with smooth 48dp pill search bar, expressive category filter chips, memory strength indicators, and quick stale memory cleanup.
  • Global Settings Search: Functional real-time search across all settings categories and options with instant navigation.
  • Native VLM & llama-kt Upgrades: VLM multimodal projector lifecycle fixes, native release memory cleanup, and updated bit-dependencies.
v2.0.8 August 10, 2026

Hotfixes for Vision Models & Advanced Search.

  • Vision Model Support: Fixed projector loading bugs preventing VLM models (SmolVLM, LFM2-VL) from fetching their multimodal projectors dynamically.
  • Advanced Store Integration: Resolved a bug where newly added VLM models from HuggingFace Explorer would not appear in the model list.
  • File Sizes in Explorer: Re-routed Explorer search to use non-recursive tree lookups so file sizes are correctly displayed instead of 0MB.
  • UI Fixes: Resolved exhaustive `when` compiler errors when rendering tags and icons for Vision models.
v2.0.7 August 10, 2026

Major Performance Overhaul: Instant TTFT, Arm KleidiAI SIMD, PowerInfer Thread Polling, New GGUF Models & Trending Search.

  • Instant TTFT Reduction: Reduced Time-To-First-Token (TTFT) from 36s to ~1s by removing speculative 3-pass routing overhead, parallelizing RAG/DataStore I/O, and caching vault memory.
  • Arm KleidiAI Hardware SIMD: Compiled hand-optimized ARM assembly micro-kernels for 4-way int8 dot-product (SDOT/UDOT) and FP16 vectorization.
  • PowerInfer Zero-Latency Busy-Polling: Integrated cfg.poll = 50 worker thread busy-polling, eliminating futex context-switch latency (~150-200µs per token).
  • Expanded Model Catalog: Added LFM2-VL 450M, SmolVLM 256M (Vision), Qwen 3 0.6B, Gemma 3 1B IT, and Gemma 2 2B IT.
  • HuggingFace Explorer & 🔥 Trending Feed: Restructured search with filter="gguf" and fast single-call siblings resolution; added Trending GGUF Models feed.
  • API Pre-Warming: Fire-and-forget TCP+TLS connection pre-warming for cloud API models, saving 200-400ms on first message.
  • 60 FPS Live UI Streaming: Throttled UI state updates to 16ms for smooth text animation and fixed thinking model output duplication.
v2.0.6 August 08, 2026

Native engine crash fixes and UI refinements.

  • Crash Fix: Bypassed a severe NDK exception unwinding crash (caused by libpdfium.so) by using raw tokenization for system prompts in the native engine.
  • Chat Logic: Fixed a bug where regenerating the last message duplicated the user prompt in the context history.
  • UI Polish: Removed the bounding box outline from the app logo, and removed the rectangular outline from the chat input box during text generation.
v2.0.5 August 07, 2026

General UI improvements and trace view transparency fixes.

  • Text Selection: Integrated custom text selection toolbar in chat messages.
  • Chat Polish: Prevented duplicate chat submissions with 1s debounce on send. Updated error handling UI for tool execution failures.
  • Trace Panel: Added query strings for web searches and URLs for fetch tools inside the trace steps. Tool agent plan is now accessible when the trace panel is expanded.
v2.0.4 August 07, 2026

UI stability improvements and generation fixes.

  • UI Polish: Eliminated text flickering/blinking during rapid token generation by throttling rendering updates.
  • UX Fix: Fixed a layout issue where the chat window would incorrectly scroll to the top after completing a response.
  • Stability: Suppressed "Failed to evaluate prompt" errors when safely cancelling or stopping generation mid-stream.
v2.0.3 August 07, 2026

Resolved remaining SIGILL engine crashes on Qualcomm and MediaTek APUs.

  • Crash Fix: Switched CPU backend from dynamic loading to a statically linked architecture. The system now safely detects runtime features natively (via KleidiAI), permanently fixing crashes that occurred during `.so` initialization on older or specific chipsets.
v2.0.2 August 06, 2026

Critical stability fix for MediaTek APU and Qualcomm CPU devices.

  • Crash Fix: Resolved an issue where llama_backend_init would auto-load incompatible CPU variants, causing a SIGILL crash on certain chipsets. Safe variants are now loaded strictly by soname before initialization.
v2.0.1 August 06, 2026

Chipset compatibility patch and native execution stability fixes.

  • Snapdragon 7s Gen 2 Fix: Resolved FP16 CPU backend instruction SIGILL crash by prioritizing safe ARMv8.2 DotProd variant during GGUF model load (LFM 350M, etc.).
  • Embedding & QNN Stability: Verified GGUF text embedding support in native C++ engine and added missing QNN asset fallback handling.
v2.0.0 August 06, 2026

Major stability update focusing on offline AI performance and model management.

  • Model Explorer: Enhanced API metrics, offline fallback catalog, and curated model store fetches.
  • Native Performance: Enabled all GGML CPU variants and dynamic backend loading for massively faster inference.
v1.9.5 July 28, 2026

CI/CD pipeline stabilization and native C++ compiler enhancements.

  • Build System: Enforced deterministic Full LTO (-flto=full) across all 5 C++ CMake modules.
  • Continuous Integration: Automated GitHub release workflows and secured release signing keys.
v1.9.0 July 19, 2026

Audio integration improvements and UI component polish.

  • Audio Handling: Multi-frame VAD barge-in with hardware AEC (Acoustic Echo Cancellation).
  • Quality of Life: Whisper artifact filtering, stop state cleanup, and HTML sanitization.
  • UI Polish: In-app APK installer Uri resolution, official logo in Settings, and dynamic layout bounds.
v1.8.4 July 17, 2026

Introduction of Claude-style Live Voice Mode.

  • Live Voice Mode: Implemented real-time voice mode with a premium monochrome visualizer aesthetic.
  • Visuals: Relocated reactive audio glow to bottom screen edges, added frosted glass top bar with haze.
  • Assets: Added HuggingFace vector SVG icon and synchronized end credits playback flow.
v1.6.3 July 10, 2026

Critical patches for LLM context and hallucinations.

  • Model Fixes: Fixed small-model prompt template leakage & sampling coherence.
  • JNI Layer: Prevented tags from leaking and fixed prompt injection to avoid hallucinations.
  • Stability: Resolved JNI chat template execution crashes and threadpool atomic alignment issues.
v1.0.0-debug July 08, 2026

Initial stable baseline.

  • Premium UI: Material 3 overhaul, top bar progressive glassmorphism, unified reasoning cards.
  • Offline Core: TTS crash fixes, multi-lingual Kokoro support, and offline TTS model downloads.
