The Philosophy

AI should work anywhere —
even without the internet.

Most AI today depends entirely on remote cloud servers. That means your personal data leaves your device, your conversations are logged, and your tools stop working the moment you lose signal.

The Status Quo

Cloud-dependent AI leaves you locked in.

Every prompt is sent over the internet to centralized data centers. You pay recurring monthly subscriptions, endure strict token rate limits, and risk sensitive personal data being analyzed or retained.

The BIT Approach

Direct on-device execution on your own silicon.

BIT runs open-weights GGUF models directly on your phone's processor using llama.cpp and llama.kt. Fast, private, zero-latency intelligence that works on planes, subways, or remote trails without a single network call.

Private by Default

Your conversations, files, and personal data stay strictly on your device. Zero telemetry, zero accounts, and zero cloud logging.

Works 100% Offline

Run text generation, vision analysis, speech recognition, and document retrieval without an internet connection.

Open Source

Inspect the source code, verify on-device execution, and build custom local applications with our Apache-2.0 native stack.

Built for Users. Engineered for Developers.

A complete local AI ecosystem — from a ready-to-use mobile assistant to native Kotlin and C++ inference libraries.

On-Device Architecture

1. GBNF Sampler Tool Router
Constrains model logits at token generation time using EBNF grammars, guaranteeing valid JSON parameter output for local tools.
2. Offline Speech Pipeline
Sherpa-ONNX offline Whisper recognition paired with VITS Piper speech synthesis running entirely on-device without remote calls.
3. Memory Vault & Hybrid RAG
Extracts episodic memory facts across sessions with decay curves and queries local PDF/TXT files using vector + BM25 search.

Per-Model Sampling & Config Controls

Tune temperature, context size, repetition penalty, system prompts, and thread allocation with instant Room DB persistence.
